项目简介
优威健身会馆管理系统是一款基于 PyQt5 和 MySQL 开发的桌面应用程序，旨在为健身会馆提供一体化的管理解决方案。系统支持会员管理、教练管理、课程管理、订单管理以及门店信息维护，同时提供直观的数据视图和便捷的增删改查操作。无论是日常运营还是数据分析，都能得心应手。
功能特点
多角色管理：管理员登录后可访问所有功能模块。
会员管理：记录会员基本信息、会员卡有效期，并自动提示即将过期的会员。
教练管理：维护教练档案，包括奖金、工作门店等。
课程管理：课程信息维护，支持按多种条件查询。
订单管理：跟踪会员购买的课程订单，监控剩余课程数量。
门店管理：管理门店信息及登录密码。
数据视图：普通用户可浏览课程、教练、门店信息。
记住密码：登录时可选择记住门店名，提升使用便捷性。
背景美化：每个界面均配有专属背景图，提升用户体验。
技术栈
前端：PyQt5（Qt Designer 设计界面）
后端：Python 3
数据库：MySQL 8.0（使用 pymysql 驱动）
其他依赖：cryptography（用于 MySQL 8.0 认证）、datetime

快速开始
环境要求
Python 3.6 或更高版本
MySQL 8.0 并创建数据库 train
操作系统：Windows /macOS/ Linux（需支持 PyQt5）
安装步骤
克隆仓库
git clone https://github.com/your-repo/fitness-management.git
cd fitness-management
安装依赖
pip install PyQt5 pymysql cryptography
若使用 MySQL 8.0 以上版本，cryptography 包为必需，否则会报认证错误。
配置数据库
启动 MySQL 服务，创建数据库 train：
CREATE DATABASE train CHARACTER SET utf8;
-- 门店表
CREATE TABLE 门店 (
  门店名称 VARCHAR(50) PRIMARY KEY,
  门店地址 VARCHAR(100),
  门店电话 VARCHAR(20),
  密码 VARCHAR(50)
);

-- 会员表
CREATE TABLE 会员 (
  会员卡号 VARCHAR(20) PRIMARY KEY,
  会员姓名 VARCHAR(50),
  会员性别 CHAR(2),
  电话 VARCHAR(20),
  会员所在门店 VARCHAR(50),
  会员卡截止日期 DATE
);

-- 教练表
CREATE TABLE 教练 (
  教练编号 VARCHAR(20) PRIMARY KEY,
  性别 CHAR(2),
  姓名 VARCHAR(50),
  工作门店 VARCHAR(50),
  奖金 DECIMAL(10,2)
);

-- 课程表
CREATE TABLE 课程 (
  课程编号 VARCHAR(20) PRIMARY KEY,
  课程名 VARCHAR(50),
  课程门店 VARCHAR(50),
  课程类型 VARCHAR(50),
  课程教练 VARCHAR(50),
  课程价格 DECIMAL(10,2)
);

-- 订单表
CREATE TABLE 订单 (
  会员名 VARCHAR(50),
  教练名 VARCHAR(50),
  课程名 VARCHAR(50),
  剩余课程数量 INT,
  PRIMARY KEY (会员名, 教练名, 课程名)
);
准备资源文件
将图片资源（0.jpg ~ 8.jpg）放置于程序运行目录，否则背景无法显示。
运行程序
启动主程序：
python test.py
📖 使用指南
登录系统
启动后进入管理员登录界面，输入门店名和密码（门店信息预存在 门店 表中）。
勾选 “记住” 可在返回登录界面时自动填充门店名。
点击 “返回” 可进入普通用户视图（仅查看课程 / 教练 / 门店信息）。
管理功能
登录成功后进入分类选择界面，点击对应按钮进入管理模块：
教练管理：可按编号、性别、姓名、工作门店查询；支持修改奖金、删除、添加教练。
会员管理：默认查询即将过期的会员（截止日期小于当天）；支持按各字段查询及增删改。
课程管理：支持按编号、课程名、门店等查询；可修改课程信息。
订单管理：默认查询剩余课程少于 5 节的订单；支持按会员名、教练名、课程名、剩余数量查询，并可修改剩余数量。
门店管理：管理门店信息及密码。
所有管理界面均提供 “返回” 按钮回到分类选择界面。

⚠️ 注意事项
数据库认证：若使用 MySQL 8.0 默认的 caching_sha2_password 插件，必须安装 cryptography 库，或修改用户认证方式为 mysql_native_password。
SQL 注入风险：部分代码使用了字符串拼接构造 SQL 语句，建议生产环境中统一改为参数化查询以提高安全性。
表名与字段名：代码中表名、字段名包含中文，请确保数据库编码为 utf8 以避免乱码。
图片资源：背景图片缺失不会导致程序崩溃，但界面美观度下降。请确保图片文件名与代码中一致。
依赖版本：PyQt5 版本 5.15.4 在部分高版本 Python 下可能存在兼容性问题，建议使用 Python 3.7~3.9。
